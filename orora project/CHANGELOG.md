# ORORA AI - Versiyon Geçmişi

## [2.0.0] - 2026-01-20

### 🚀 Major Changes
- **Tam C++ Native**: Tüm Python bağımlılıkları kaldırıldı
- **Yeni Ses Sistemi**: Whisper.cpp STT + VITS TTS
- **Metahuman Render**: OpenGL + SSS shaders
- **3D Oda Sistemi**: Etkileşimli mobilyalar

### ✨ Yeni Özellikler
- Voice Cloning (ses klonlama)
- 125+ blend shape yüz ifadesi
- A* pathfinding ile oda navigasyonu
- 16 saç rengi ve stili
- Kıyafet ve outfit sistemi
- Qt6 sohbet paneli
- Setup wizard (cinsiyet seçimi)

### 🗑️ Kaldırılan
- `orora_server/` - Python sunucular
- `bark_env/` - Python virtual environment
- `bark_server.py` - Bark TTS wrapper
- `xtts_v2/` - Eski TTS sistemi

### 🛠️ Teknik
- CMake build system
- vcpkg dependency management
- 5 birim test dosyası
- Profesyonel dokümantasyon
